Smart Revise Gimmick-style Bot

A Safari bookmarklet prototype for adding a floating auto-answer panel to Smart Revise.

Quick setup

  1. Publish this repository with GitHub Pages using the /public folder.
  2. Create a Safari bookmark named Smart Revise Bot.
  3. Replace its URL with the bookmarklet in README.md.
  4. Open a Smart Revise question and tap the bookmark.

Experimental prototype: detection depends on Smart Revise's page HTML and may need tuning after testing.

New: select page elements

  1. Tap Select question area, then tap the question text.
  2. Tap Select one answer button, then tap one answer choice. The script attempts to find the other answer buttons in the same group.
  3. Tap Select Next Question button, then tap the next button.
  4. Selections are stored in Safari local storage. Use Reset selections if the page layout changes.

This selects webpage elements, not screen coordinates. It requires readable text and clickable controls in the page's DOM.
