Smart Revise Gimmick-style Bot

A Safari bookmarklet prototype for adding a floating auto-answer panel to Smart Revise.

Quick setup

  1. Publish this repository with GitHub Pages using the /public folder.
  2. Create a Safari bookmark named Smart Revise Bot.
  3. Replace its URL with the bookmarklet in README.md.
  4. Open a Smart Revise question and tap the bookmark.

Experimental prototype: detection depends on Smart Revise's page HTML and may need tuning after testing.
